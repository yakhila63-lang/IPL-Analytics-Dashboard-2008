IPL Analytics Dashboard 2008.
🏏Interactive IPL 2008 season analysis using Python, Streamlit & Plotly. This dashboard visualizes the inaugural IPL season where Rajasthan Royals won.
🚀 Live Demo.
Deploying soon on Streamlit Cloud
📊 Features
Team-wise Filtering: Select any team to view their complete season stats
Key Metrics: Total matches, wins, win percentage, toss decisions
Interactive Charts: Wins by team and toss analysis with Plotly
Full Data Table: Explore the raw 2008 IPL match data
🛠️ Tech Stack
Python: Pandas for data manipulation
Streamlit: For building the interactive web app
Plotly: For creating beautiful interactive charts
Dataset: IPL 2008 matches CSV
